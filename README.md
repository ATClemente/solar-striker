# SolarStriker Disassembly

This project is a disassembly of the game SolarStriker. 

It builds the following ROM: 

game.gb 
`SHA-1: a8d6acb026b0d0a8a2bcaea094951e915a3deb80`

## Building

To build the project you will need to install [RGBDS](https://rgbds.gbdev.io/docs/v1.0.4/)

You will also need `make`

From the root directory run:

`make`

To build and verify checksum run: 

`make verify`

To clean run:

`make clean`
